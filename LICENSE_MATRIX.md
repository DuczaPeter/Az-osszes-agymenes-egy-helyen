# License Matrix

A cél nem az, hogy a különálló sPg repositoryk licenceit mesterségesen egységesítsük.

| Scope | Licenc / státusz | Megjegyzés |
|---|---|---|
| `DuczaPeter.github.io` landing oldal saját HTML/CSS/JS kódja | MIT | Lásd `LICENSE`. |
| E repository saját dokumentációja | MIT | Kivéve idézett vagy külső tartalom. |
| `sPg-UEX-Eladas` | Unlicense – a repository README alapján | Mindig az adott repo aktuális LICENSE/README fájlja az irányadó. |
| `sPg-UEX-Vasarlas` | MIT – a repository README alapján | Mindig az adott repo aktuális LICENSE/README fájlja az irányadó. |
| Többi linkelt sPg repository | Nem állítunk egységes licencet | Ellenőrizd az adott repository `LICENSE`, `README` és notices fájljait. |
| Star Citizen / CIG / RSI IP | Nem része az MIT licencnek | A jogosultak jogai fennmaradnak. |
| Star Citizen Wiki API kód | MIT a saját upstream repository szerint | Az API által szolgáltatott játékadatok/fordítások ettől eltérhetnek. |
| UEX adatok és szolgáltatás | UEX saját feltételei | Lásd UEX Terms / API Terms. |
| SCMDB adatok | Nincs itt újralicencelve | Csak hivatkozás; ne feltételezz szabad újraelosztást. |

## Szabály

Ha egy linkelt projekt licence később változik, ezt a fájlt csak ellenőrzött repository-adat alapján frissítsd. Ne következtess licencre pusztán abból, hogy a repository publikus.
