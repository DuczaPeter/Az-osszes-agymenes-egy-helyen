# Contributing

Köszönöm, ha segítesz javítani az sPg központi landing oldalt.

## Mit lehet javítani?

- hibás vagy megszűnt projektlink;
- elavult projektleírás;
- helyesírás;
- mobilos megjelenítés;
- akadálymentesség;
- új publikus sPg projekt felvétele;
- jogi/forráslink frissítése;
- szűrés vagy keresés hibája.

## Kötelező szabályok

1. A landing oldal runtime továbbra is egyetlen `index.html`.
2. Ne adj hozzá külön runtime CSS vagy JS függőséget.
3. Ne találj ki projektfunkciót. README-ből vagy a tényleges programból ellenőrizd.
4. A nem hivatalos fan-site figyelmeztetés maradjon jól látható.
5. Ne commitolj API-kulcsot, tokent vagy személyes adatot.
6. Külső adatforrás licenceit ne írd felül a landing MIT licencével.
7. A projekt URL-eket és GitHub Pages címeket módosítás előtt ellenőrizd.

## Javasolt folyamat

- Fork vagy új branch.
- Módosítás.
- `index.html` megnyitása Chrome/Edge alatt.
- Mobil szélesség ellenőrzése.
- Linkek ellenőrzése.
- Pull Request rövid változásleírással.
