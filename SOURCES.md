## Star Citizen Wiki

- API alapcím: https://api.star-citizen.wiki/
- API dokumentáció: https://docs.star-citizen.wiki/
- API GitHub: https://github.com/StarCitizenWiki/API

A Star Citizen Wiki API alkalmazáskódja MIT licencű. Az API által közvetített vagy kivont játékadatok és egyes fordítások ettől eltérő jogi feltételek alá eshetnek, ezért harmadik fél adatait nem szabad automatikusan a landing repository MIT licence alá sorolni.

## UEX

- Weboldal: https://uexcorp.space/
- Terms of Use / Privacy / API Terms: https://uexcorp.space/about/terms?set_lang=en_US
- API dokumentáció: https://uexcorp.space/api/documentation/id/home?set_lang=en_US
- API 2.0: https://api.uexcorp.uk/2.0/

A UEX közösségi adatforrás. A feltételeik személyes, nem kereskedelmi felhasználást írnak le a weboldalhoz, az API-hoz pedig külön API Terms vonatkozik. A kapcsolt sPg eszközöknek ezeket külön-külön be kell tartaniuk.
