# sPg Star Citizen Tools

This repository hosts the **central landing page for DuczaPeter / sPg Star Citizen community projects**.

The purpose is to provide one place where users can discover the public sPg tools, understand what each tool is for, read a short usage guide, and open either the live page or its GitHub repository.

## Live site

https://duczapeter.github.io/

## Repository contents

- `index.html` – the complete landing page with embedded CSS and JavaScript.
- `README.md` – Hungarian main documentation.
- `README_EN.md` – this English documentation.
- `PROJECTS.md` – project catalog.
- `SOURCES.md` – external sources and providers.
- `LICENSE` – MIT license for the landing-page code.
- `LICENSE_MATRIX.md` – license-boundary notes for linked projects.
- `THIRD_PARTY_NOTICES.md` – Star Citizen / CIG / RSI and third-party notices.
- `PRIVACY.md` – privacy summary.
- `SECURITY.md` – security and secrets policy.
- `CONTRIBUTING.md` – contribution guide.
- `AGENTS.md` – Codex / AI developer handoff and non-negotiable rules.
- `DEPLOY_GITHUB_PAGES.md` – deployment guide.
- `CHANGELOG.md` – change log.
- `.nojekyll`, `robots.txt`, `sitemap.xml` – GitHub Pages support files.
- `.github/ISSUE_TEMPLATE/` – bug and feature-request templates.

## Single-file runtime

The public landing page itself is a true single-file HTML page. All CSS and JavaScript required for the landing page are embedded into `index.html`. The additional files exist for documentation, legal notices, maintenance and future development.
