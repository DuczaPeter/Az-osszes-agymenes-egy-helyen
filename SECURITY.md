# Security

## Titkok

Ebbe a repositoryba tilos feltölteni:

- UEX API tokent;
- személyes API-kulcsot;
- jelszót;
- privát logfájlt;
- személyes készletexportot;
- privát screenshotot;
- bármilyen más titkos vagy azonosító adatot.

A landing page működéséhez nincs szükség tokenre vagy secretre.

## Külső linkek

A projektlinkeket kizárólag ellenőrzött GitHub repository vagy ismert hivatalos/közösségi szolgáltató címére állítsd.

## Hibajelzés

Hibát GitHub Issue formájában jelents. Biztonsági problémánál ne tegyél közzé valódi kulcsot vagy személyes adatot a hibajegyben.
